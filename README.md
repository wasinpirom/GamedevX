# GamedevX — AI สร้างเกม Visual Novel

เว็บสตูดิโอที่ให้ AI สร้างเกม Visual Novel ครบชุด ได้แก่ บทเกม ตัวละครหลายสีหน้า ฉากหลัง และเพลงประกอบ
ผู้ใช้ทดลองเล่นบนเว็บได้ทันที แล้วส่งออกเป็น **โปรเจกต์ Ren'Py**, **เกมเว็บ (HTML)** หรือ **ชุด asset จริง** (PNG/JPG/เพลง + `story.json`)

- AI เขียนเรื่อง/ภาพ: **OpenRouter**
- ภาพ (ทางเลือก), ลบพื้นหลัง, แต่งเพลง: **fal.ai**
- ระบบสมาชิก + เครดิต: ผู้ใช้เห็นราคาก่อนกดตกลงทุกครั้ง งานล้มเหลวคืนเครดิตอัตโนมัติ
- การเติมเครดิต: ลูกค้าจ่ายผ่าน LINE OA / KWAY PAY แล้วแอดมินกดเติมในหน้า `/admin` (ไม่ต้องเชื่อม payment)

---

## Deploy บน Coolify (ประมาณ 10 นาที)

1. **อัปโหลดโค้ดขึ้น GitHub**: สร้าง repo ใหม่ (private ก็ได้) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. **Coolify → + New Resource → Private/Public Repository** → เลือก repo นี้
3. **Build Pack: `Dockerfile`** · **Ports Exposes: `8000`**
4. **Domains:** `https://gamedevx.com` (ชี้ DNS A record ของโดเมนมาที่ IP เซิร์ฟเวอร์ Coolify ก่อน)
5. **Persistent Storage** (สำคัญมาก ถ้าไม่ตั้ง ข้อมูลจะหายเมื่อ deploy ใหม่) → Add → Volume Mount
   - Destination Path: **`/data`**
6. **Environment Variables:** คัดลอกจาก `.env.example` แล้วใส่ค่าจริง

   | ตัวแปร | ค่า |
   |---|---|
   | `OPENROUTER_API_KEY` | คีย์จาก openrouter.ai/keys |
   | `FAL_KEY` | คีย์จาก fal.ai/dashboard/keys |
   | `ADMIN_EMAIL` | อีเมลแอดมิน (ระบบสร้างบัญชีให้ตอนเปิดครั้งแรก) |
   | `ADMIN_PASSWORD` | รหัสผ่านแอดมิน อย่างน้อย 8 ตัว |
   | `SECRET_KEY` | ข้อความสุ่มยาว ๆ (เช่น ผลจาก `openssl rand -hex 32`) |
   | `SITE_URL` | `https://gamedevx.com` |
   | `LINE_OA_ID` | `@wasin` |
   | `KWAY_SHOP_URL` | `https://kway.app/shop` |
   | `MOCK_AI` | `0` (ใส่ `1` ถ้าอยากลองระบบโดยไม่เรียก API จริง) |

7. กด **Deploy** แล้วรอ build เสร็จ จากนั้นเปิด `https://gamedevx.com`
8. เข้าสู่ระบบด้วย `ADMIN_EMAIL` แล้วไปที่ **`/admin`**
   - แท็บ **ตั้งค่า & ราคา**: ตั้งราคาเครดิต แพ็กเกจ และโมเดล AI
   - แท็บ **คลังเพลง**: อัปโหลดเพลงตามอารมณ์ (สดใส, เศร้า, ลุ้นระทึก ฯลฯ) ระบบจะเลือกใส่เกมให้อัตโนมัติ
   - กดปุ่ม **ทดสอบ OpenRouter** เพื่อเช็กคีย์

> แนะนำ: deploy ครั้งแรกด้วย `MOCK_AI=1` เพื่อลองทุกหน้าโดยไม่เสียเงิน พอใช้ได้แล้วค่อยเปลี่ยนเป็น `0` แล้ว Redeploy

## การเติมเครดิตให้ลูกค้า

1. ลูกค้าสมัครสมาชิก (ได้เครดิตฟรีตามที่ตั้งไว้) แล้วไปหน้า **เติมเครดิต** จะเห็น **รหัสสมาชิก #**
2. ลูกค้าจ่ายเงินผ่าน LINE OA หรือ KWAY PAY แล้วแจ้งรหัสสมาชิก
3. แอดมินเข้า `/admin` → ค้นหารหัสหรืออีเมล → **เติมเครดิต** → ใส่จำนวนและหมายเหตุ (เช่น "โอน 99 บาท KWAY")
4. ทุกรายการถูกบันทึกในประวัติเครดิต ทั้งฝั่งลูกค้าและแอดมิน

## การเลือกโมเดล AI (เปลี่ยนได้ที่ /admin โดยไม่ต้อง deploy ใหม่)

| การตั้งค่า | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|
| `or_text_model` | `anthropic/claude-sonnet-4.5` | ใช้เขียนบท ถ้าอยากประหยัดลอง `google/gemini-2.5-flash` หรือ `deepseek/...` |
| `image_provider` | `openrouter` | หรือ `fal` |
| `or_image_model` | `google/gemini-2.5-flash-image` | ต้องเป็นโมเดลบน OpenRouter ที่สร้างภาพได้ และรับภาพอ้างอิงได้ (ใช้คุมหน้าตัวละครให้เหมือนเดิม) |
| `fal_image_model` | `fal-ai/flux/dev` | ใช้เมื่อ `image_provider=fal` |
| `fal_image_edit_model` | `fal-ai/nano-banana/edit` | ใช้สร้างสีหน้าอื่นจากภาพหลักของตัวละคร |
| `fal_bg_remove_model` | `fal-ai/birefnet` | ลบพื้นหลังตัวละคร (เว้นว่าง = ใช้ตัวลบพื้นขาวในเครื่อง ฟรีแต่คุณภาพต่ำกว่า) |
| `fal_music_model` | `fal-ai/stable-audio` | รองรับ `fal-ai/ace-step`, `fal-ai/elevenlabs/music` และโมเดลที่รับ `prompt` + `duration` |

ก่อนเปิดขายจริง ให้ลองสร้างงาน 1 ชุดแล้วดูค่าใช้จ่ายจริงใน OpenRouter/fal เพื่อตั้งราคาเครดิตให้มีกำไร
และตรวจเงื่อนไขการใช้งานเชิงพาณิชย์ของโมเดลที่เลือก

## หน้าแรกแบบ GamedevX ดั้งเดิม (community + เว็บบอร์ด)

หน้าแรกและหน้ากระทู้จำลองหน้าตาเว็บ GamedevX เดิม (ราวปี 2550) ได้แก่ แถบหัวสีม่วง, กล่อง GamedevX Member (username/password/Remember/Sign In),
เว็บบอร์ด (Show All, Post Topic, ค้นหา, ลำดับ/กระทู้/ตั้งโดย/วันที่/ตอบล่าสุด/อ่าน-ตอบ, ไอคอน PHOTO และ NEW!) และคอลัมน์ "Wasin Pirom's GamedevX History"

**ให้เหมือนเดิม 100%:** อัปโหลดภาพโลโก้และภาพตัวการ์ตูน GamedevX เดิมที่ `/admin` → **โฆษณา & แบนเนอร์**
ตำแหน่ง "โลโก้" กับ "ภาพส่วนหัว" แล้วใส่แบนเนอร์ E-Learning เดิมในตำแหน่ง "กลางหน้าแรก" (ถ้ายังไม่มีไฟล์เดิม หาได้จาก web.archive.org)

### เว็บบอร์ด
- สมาชิกตั้งกระทู้ แนบรูปได้ เลือกหมวด และแชร์เกมที่สร้างด้วย AI ให้เล่นในกระทู้ได้
- login ด้วย username หรืออีเมล (username ห้ามซ้ำ)
- เปิดให้ Guest โพสต์ได้ (ตั้งค่า `allow_guest_post`) มีตัวกันสแปม (honeypot + จำกัดจำนวนโพสต์ต่อ IP)
- ตั้งคำต้องห้ามได้ (`bad_words`) ระบบแทนคำเหล่านั้นด้วย ***

### หลังบ้าน → เว็บบอร์ด
- ค้นหากระทู้หรือความเห็นด้วยข้อความ ชื่อผู้โพสต์ หรือ IP
- แก้ไขข้อความ, ปักหมุด, ล็อก (ห้ามตอบ), ซ่อน, ลบ, ลบรูปที่แนบ, แบนผู้ใช้ในคลิกเดียว

### หลังบ้าน → โฆษณา & แบนเนอร์
| ตำแหน่ง | ใช้ทำอะไร |
|---|---|
| โลโก้ | แทนโลโก้ตัวอักษร (สูงไม่เกิน 130px) |
| ภาพส่วนหัว | ตัวการ์ตูน/ภาพกลางแถบม่วง (สูง 130px) |
| กลางหน้าแรก | แบนเนอร์ใหญ่ (หลายภาพหมุนอัตโนมัติ) |
| คอลัมน์ซ้าย | โฆษณา / บทสัมภาษณ์ (กว้าง 125px) |
| คอลัมน์ขวา | ประวัติ / ข่าว (ภาพกว้าง 170px + ข้อความ) |

ทุกแบนเนอร์ใส่ลิงก์ได้ ระบบนับจำนวนคลิก และตั้งวันเริ่ม/วันหมดอายุได้ (เหมาะกับการขายพื้นที่โฆษณา)

## ภาพอ้างอิง (ให้ตัวละครหน้าคล้ายเรา)

ในแท็บ **ตัวละคร** / **ฉากหลัง** มีช่อง "ภาพอ้างอิง" อัปโหลดภาพถ่ายหรือภาพสเก็ตช์ได้
ระบบส่งภาพนี้ให้โมเดลภาพวาดตัวละครหรือฉากให้คล้ายต้นฉบับในสไตล์ของเกม (สีหน้าอื่น ๆ จะวาดต่อจากภาพหลักเพื่อให้หน้าเหมือนกันทุกภาพ)
ต้องใช้โมเดลภาพที่รับภาพอ้างอิงได้ ค่าเริ่มต้นใช้ได้แล้ว: `google/gemini-2.5-flash-image` (OpenRouter) หรือ `fal-ai/nano-banana/edit` (fal)

## วิดีโอ MP4 สำหรับ YouTube

แท็บ **ส่งออก** → **วิดีโอ MP4** → เลือกเส้นทางของเรื่อง (ถ้าเกมมีหลายทางเลือก) → เรนเดอร์
ได้วิดีโอ 1280×720 ที่มีหน้าชื่อเรื่อง ตัวละคร บทพูด ทางเลือก เพลงประกอบ และหน้าจบพร้อมลายน้ำเว็บ
เรนเดอร์บนเซิร์ฟเวอร์ด้วย ffmpeg (มีใน Dockerfile แล้ว) ไม่เรียก API ภายนอก ราคาตั้งได้ที่ `cost_video`

## ฟีเจอร์

- **สร้างเกมใหม่**: ใส่ไอเดีย แนวเกม สไตล์ภาพ จำนวนฉากและตัวละคร แบบมีทางเลือกหรือเส้นเดียว ภาษาไทยหรืออังกฤษ
- **สตูดิโอ**
  - บทเกม: แก้ข้อความ เปลี่ยนสีหน้า เพิ่ม/ลบบรรทัดและฉาก ทางเลือก ตอนจบ ให้ AI เขียนฉากใหม่ แก้แบบ JSON
  - ตัวละคร / ฉากหลัง: เลือกภาพที่ต้องการแล้วดูราคารวมก่อนสร้าง อัปโหลดภาพของตัวเองได้ฟรี
  - เพลง: เลือกจากคลัง (ฟรี) หรือให้ AI แต่งใหม่
  - ทดลองเล่นบนเว็บ ทั้งแบบเต็มจอและเล่นจากฉากที่ต้องการ
  - ส่งออกเป็น Ren'Py, เกมเว็บ หรือชุด asset
- **Ren'Py export**: ได้ `script.rpy`, ฟอนต์ไทย (Loma, GPL + font exception), ตัดคำไทยให้ขึ้นบรรทัดถูกต้อง, ภาพ, เพลง และ README วิธีเปิด
- **หลังบ้าน**: สถิติ สมาชิก เติม/หักเครดิต รีเซ็ตรหัสผ่าน ระงับบัญชี ประวัติเครดิต รายการงาน AI คลังเพลง ตั้งราคาและโมเดล

## รันบนเครื่องตัวเอง (สำหรับนักพัฒนา)

```bash
pip install -r requirements.txt   # ต้องมี ffmpeg ในเครื่องด้วยถ้าจะทดสอบวิดีโอ
DATA_DIR=./data MOCK_AI=1 COOKIE_SECURE=0 ADMIN_EMAIL=admin@test.com ADMIN_PASSWORD=admin12345 \
  uvicorn app.main:app --reload --port 8000
# เปิด http://localhost:8000
```

## โครงสร้างไฟล์

```
Dockerfile, requirements.txt, .env.example
app/
  main.py        เส้นทางเว็บและ API ทั้งหมด
  pipeline.py    AI agent: วางโครงเรื่อง สร้างภาพ เพลง ประเมินเครดิต และคิวงาน
  video.py       เรนเดอร์วิดีโอ MP4 (Pillow + ffmpeg)
  community.py   เว็บบอร์ด ความเห็น โฆษณา/แบนเนอร์ และหลังบ้านจัดการบอร์ด
  providers.py   ตัวเชื่อม OpenRouter + fal.ai (และโหมด MOCK)
  export.py      ส่งออก Ren'Py / เว็บ / asset
  imaging.py     ปรับภาพให้พร้อมใช้ในเกม (ขนาด ลบพื้นหลัง)
  db.py, auth.py, config.py
  pages/         หน้าเว็บ (HTML)
  static/        CSS, JS, ตัวเล่นเกม (player.js)
  renpy_template/  ฟอนต์ไทยและไฟล์ตั้งค่าสำหรับ Ren'Py
```

ข้อมูลทั้งหมดอยู่ใน `/data`: `gamedevx.db` (SQLite), `projects/` (ภาพ/เพลง/ภาพอ้างอิง/วิดีโอของแต่ละโปรเจกต์), `music/` (คลังเพลง), `banners/` (แบนเนอร์), `board/` (รูปในเว็บบอร์ด)
สำรองข้อมูลด้วยการ backup volume `/data` ทั้งโฟลเดอร์

ระบบออกแบบให้รันแบบ 1 instance (1 worker) เพราะคิวงาน AI ทำงานในโปรเซสเดียวกัน
รองรับผู้ใช้หลักร้อยคนสบาย ๆ ถ้าโตกว่านั้นค่อยย้ายเป็น PostgreSQL + Redis queue
